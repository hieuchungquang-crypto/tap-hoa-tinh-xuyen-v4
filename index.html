Lịch sử hóa đơn

Mục tiêu 10.000 hóa đơn trên thiết bị. Không tự xóa đơn cũ. Có thể tìm theo mã đơn, ngày, khách hoặc tên sản phẩm.

Sao lưu dữ liệu

Dữ liệu chỉ nằm trên thiết bị/trình duyệt này. Xóa dữ liệu trình duyệt, đổi điện thoại hoặc dùng chế độ ẩn danh có thể làm mất dữ liệu. Hãy tải bản sao lưu thường xuyên và cất ở nơi an toàn.

File JSON giữ đầy đủ dữ liệu để khôi phục; file Excel phục vụ kiểm tra, thống kê. Nếu không tải được thư viện Excel, phần mềm xuất CSV tương thích Excel.

Khôi phục từ bản sao lưu JSON

Khôi phục sẽ thay thế danh sách sản phẩm và lịch sử hóa đơn trên thiết bị này. Phần mềm sẽ yêu cầu xác nhận trước.
